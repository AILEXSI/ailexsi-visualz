# Audio → visual bindings

| Source | Visual |
|--------|--------|
| Bass | mass / size (core radius, filament spacing) |
| Kick | impulse (pulse flash, ring snap) |
| Snare | geometric break (kink in filaments) |
| Hi-hat | glitter / fine particles |
| Vocals | organic drift (phase + vertical sway) |
| Build-up | camera push-in + densify |
| Drop | full escalation (amp, bloom, extra filaments) |

Kick ≠ bass. Right-side bars stay treble-gated.
